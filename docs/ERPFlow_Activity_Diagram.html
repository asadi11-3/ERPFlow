Financial Governance & Approval Thresholds Enforced at API & Domain
1
High-Value Authorization Ceiling ($10,000 Rule):

Standard Approver role can approve orders up to $10,000. Orders exceeding $10,000 require Administrator privileges; non-admin attempts are rejected with 403 Forbidden.

2
Mandatory Rejection Documentation:

Rejecting an order strictly requires a non-blank audit reason. Empty rejection reasons fail client validation and are rejected with 400 Bad Request.

3
Return for Correction Loop:

Approvers can return an order to Draft status with notes. All reserved warehouse stock is immediately released, allowing the sales representative to adjust quantities or pricing without deadlocks.

Post-Sale Machinery & Field Service Flow Equipment Lifecycle
•
Automated Machine Provisioning:

Dispatching an approved sales order generates a permanent MachineAsset with initial meter count, warranty expiration date (+1 year), and registered customer site.

•
Service Dispatch & Jobcards:

Maintenance tasks (Preventive, Breakdown, Meter Audit) dispatch a Jobcard to an assigned field technician with real-time status tracking (Open → InProgress → Completed).

•
Spare Parts Requisition & Meter Telemetry:

Technicians request spare parts directly into the jobcard (updating inventory in real time) and record latest machine odometer readings upon job closure.
